# 📝 Notes Hamza (v2.0)

تطبيق سطح مكتب متطور لنظام ويندوز لإدارة الملاحظات والمهام اليومية بواجهة عصرية داكنة، مبني بلغة **Python** ومكتبة **CustomTkinter**.

## ✨ المميزات المتقدمة
- 🔒 **حماية الملاحظات بكلمة مرور:** إمكانية قفل الملاحظات السرية بكلمة مرور خاصة.
- ⏰ **نظام تنبيهات صوتي للمهام:** تحديد وقت تذكير لكل مهمة مع نافذة تنبيه وصوت منبه عند حلول الموعد.
- ✅ **قائمة مهام ذكية (Advanced To-Do):** تحديد الأولويات (High, Medium, Low) وحساب نسبة الإنجاز تلقائياً.
- 📌 **تنظيم وبحث فوري:** تصنيف الملاحظات، تثبيتها في الأعلى، وبحث لحظي.
- 📤 **تصدير الملاحظات:** حفظ الملاحظات والمهام بصيغة Markdown (`.md`) أو نص عادي (`.txt`).

## 🚀 طريقة التشغيل وبناء نسخة الويندوز
1. **للتشغيل المباشر:**
   ```bash
   pip install -r requirements.txt
   python main.py
   ```
2. **لتحويله لبرنامج ويندوز مستقل (`.exe`):**
   قم بتشغيل ملف `build_exe.bat` بالنقر المزدوج عليه، وستجد البرنامج جاهزاً داخل مجلد `dist`.
